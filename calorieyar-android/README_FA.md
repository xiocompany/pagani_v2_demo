# کالری‌یار Android V1

نسخه اول قابل توسعه‌ی یک اپلیکیشن ثبت غذا، فعالیت و کالری روزانه با رابط فارسی RTL و معماری Local-first.

## امکانات V1
- داشبورد کالری روزانه و کالری باقی‌مانده
- نمایش پروتئین، کربوهیدرات و چربی
- بانک اولیه ۴۰+ غذای ایرانی و عمومی
- واحدهای رایج ایرانی مثل کفگیر، سیخ، کف دست، ملاقه و پیاله
- جستجوی غذا و ثبت وعده
- ثبت ۱۴ نوع فعالیت و محاسبه با MET و وزن کاربر
- تاریخچه روزانه و حذف رکورد
- هدف کالری و وزن
- ۴ یادآوری قابل فعال/غیرفعال شدن
- ذخیره‌سازی آفلاین روی دستگاه
- آماده برای اضافه شدن MCP/ChatGPT در نسخه‌های بعد

## تکنولوژی
- Native Android / Java 17
- minSdk 23
- targetSdk 35
- Android Gradle Plugin 8.7.3
- Gradle 8.9 در CI
- بدون کتابخانه UI سنگین یا سرویس خارجی در V1

## معماری V1
هسته محاسبه کالری (`NutritionMath`) از UI مستقل است. کاتالوگ غذا و فعالیت (`FoodDatabase`)، ذخیره‌سازی (`DataStore`) و Reminder نیز کلاس‌های مستقل دارند. این جداسازی اجازه می‌دهد در نسخه بعد Repository/API/MCP بدون تغییر موتور اصلی اضافه شود.

## کیفیت و Build
CI روی GitHub برای هر Push به branch نسخه V1 این مراحل را اجرا می‌کند:
1. Unit tests
2. Android Lint
3. Build Debug APK
4. بررسی وجود و غیرخالی بودن APK
5. انتشار APK به‌عنوان GitHub Actions Artifact

## Build محلی
پروژه را با Android Studio باز کنید و از Build > Build APK(s) استفاده کنید. JDK 17 لازم است.

## نکته پزشکی
این برنامه در V1 ابزار ثبت و تخمین کالری است و جایگزین توصیه پزشک یا متخصص تغذیه نیست.
